# SKALA 스토어 반품·교환 규정 (2026-08 개정)

## 1. 반품 가능 기간

- 단순 변심: 상품 수령일로부터 **7일 이내**
- 상품 하자·오배송: 수령일로부터 **30일 이내**
- 신선식품·주문제작 상품: 단순 변심 반품 **불가**

## 2. 반품 배송비

| 사유 | 부담 주체 | 금액 |
| --- | --- | --- |
| 단순 변심 | 고객 | 편도 3,000원 (제주·도서산간 6,000원) |
| 상품 하자 | 회사 | 무료 |
| 오배송 | 회사 | 무료 |

## 3. 반품 불가 사유

다음의 경우 반품이 제한된다.

1. 상품을 사용하거나 일부 소비해 가치가 현저히 감소한 경우
2. 시간이 지나 재판매가 곤란할 정도로 상품 가치가 감소한 경우
3. 복제 가능한 상품의 포장을 훼손한 경우
4. 고객의 주문에 따라 개별 제작된 상품

## 4. 교환 절차

1. 고객센터 또는 챗봇에서 교환을 접수한다.
2. 접수 번호가 발급되며, 담당자 승인 후 처리된다.
3. 승인되면 회수 택배가 1~2영업일 내 방문한다.
4. 회수 완료 후 재발송까지 통상 2~3영업일이 걸린다.

## 5. 환불 처리 기간

- 카드 결제: 회수 확인 후 **3영업일 이내** 승인 취소
- 계좌 이체: 회수 확인 후 **1영업일 이내** 입금
- 포인트: 즉시 복원
