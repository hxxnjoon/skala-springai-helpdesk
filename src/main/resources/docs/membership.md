# SKALA 스토어 멤버십 규정 (2026-08 개정)

## 1. 등급 기준

최근 12개월 누적 구매 금액을 기준으로 매월 1일 자동 산정된다.

| 등급 | 산정 기준 (최근 12개월 누적 구매액) |
| --- | --- |
| 그린 | 신규 가입 시 기본 부여 |
| 실버 | 30만 원 이상 |
| 골드 | 100만 원 이상 |
| VIP | 300만 원 이상 |

## 2. 등급별 혜택

| 등급 | 포인트 적립률 | 배송비 | 생일 쿠폰 |
| --- | --- | --- | --- |
| 그린 | 0.5% | 기본 배송비 적용 | 미지급 |
| 실버 | 1% | 3만 원 미만 주문도 무료 | 3,000원 |
| 골드 | 3% | 무료 | 5,000원 |
| VIP | 5% | 무료 + 당일 배송 우선 처리 | 10,000원 |

- 포인트 적립률은 결제 금액(배송비 제외) 기준으로 계산한다.
- VIP 등급은 [배송 규정](shipping-policy.md)의 당일 배송 조건을 충족하지 않아도 우선 처리된다.

## 3. 포인트 적립·사용

- 적립: 주문이 **배송완료** 상태로 전환된 다음 날 자동 적립된다.
- 사용: 1점 = 1원, 최소 1,000점부터 100점 단위로 사용할 수 있다.
- 유효기간: 적립일로부터 **1년**이며, 만료 30일 전 알림을 발송한다.
- [반품·교환 규정](return-policy.md)에 따라 환불되면 해당 주문으로 적립된 포인트는 회수된다.

## 4. 등급 조정

1. 매월 1일, 직전 12개월 누적 구매액을 재산정해 등급을 조정한다.
2. 등급 상승은 즉시 적용되며, 하락은 3개월 유예 기간을 둔 뒤 적용된다.
3. 반품·취소로 확정된 구매액은 누적 구매액 산정에서 제외된다.

## 5. 유의 사항

- 멤버십 혜택은 본인 명의 주문에만 적용되며 양도할 수 없다.
- 부정 적립(허위 주문·어뷰징)이 확인되면 적립 포인트를 회수하고 등급을 강등할 수 있다.
