# SKALA 스토어 배송 규정 (2026-08 개정)

## 1. 배송 소요 기간

| 지역 | 일반 배송 | 당일 배송 |
| --- | --- | --- |
| 수도권 | 1~2영업일 | 평일 14시 이전 주문 시 가능 |
| 광역시 | 2~3영업일 | 불가 |
| 그 외 지역 | 2~4영업일 | 불가 |
| 제주·도서산간 | 3~5영업일 | 불가 |

## 2. 배송비

- 3만 원 이상 주문: **무료**
- 3만 원 미만: 3,000원
- 제주·도서산간 추가: 3,000원

## 3. 배송 상태 표기

| 상태 | 의미 |
| --- | --- |
| 결제완료 | 주문이 접수되었고 출고 대기 중이다 |
| 상품준비중 | 창고에서 포장이 진행 중이다 |
| 배송중 | 택배사에 인계되어 이동 중이다 |
| 배송완료 | 수령지에 전달되었다 |

## 4. 배송 지연

천재지변·명절 물량 폭주 등으로 지연될 수 있다.
3영업일 이상 지연되면 고객에게 개별 안내하며, 고객은 주문을 취소할 수 있다.

## 5. 주소 변경

- 상품준비중 단계까지는 고객센터를 통해 변경할 수 있다.
- 배송중 단계부터는 변경할 수 없으며, 반송 후 재주문해야 한다.
